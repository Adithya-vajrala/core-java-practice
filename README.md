# Core Java Practice

## About This Repository

This repository documents my journey toward becoming a Java Full Stack Developer. I use it to learn Core Java concepts, implement practical examples, solve coding exercises, and prepare for technical interviews.

My focus is on understanding concepts deeply and writing code independently rather than copying solutions from tutorials.

## Learning Approach

I follow a structured learning workflow:

1. **Learn:** Understand the concept, why it is needed, and how it works.
2. **Note:** Write concise notes covering definitions, key concepts, examples, and common mistakes.
3. **Implement:** Write Java code independently to demonstrate my understanding.
4. **Practice:** Solve exercises of increasing difficulty without immediately looking at solutions.
5. **Test:** Verify the code with normal inputs, edge cases, and invalid inputs where applicable.
6. **Review:** Improve code readability, naming, correctness, and design.
7. **Commit and Push:** Upload completed work to GitHub with meaningful commit messages.
8. **Explain:** Practise explaining the concept and implementation in my own words, as I would in a technical interview.

## Coding Principles

- Write readable, maintainable Java code.
- Use meaningful class, method, and variable names.
- Follow Java naming conventions and appropriate access modifiers.
- Understand the code before committing it.
- Test implementations rather than assuming they work.
- Record mistakes and the lessons learned from debugging.
- Avoid committing passwords, API keys, or other sensitive information.

## Git and GitHub Workflow

I use Git to track my learning progress and maintain a professional development history.

My workflow is:

1. Complete a small, meaningful unit of work.
2. Review and test the changes.
3. Check the files using `git status`.
4. Stage the relevant files.
5. Commit with a descriptive message.
6. Push the changes to GitHub.

Example commit messages:

- `feat(basics): add primitive data type examples`
- `feat(oop): demonstrate method overriding`
- `test(strings): add palindrome test cases`
- `docs: update learning notes`

## Progress Tracking

For each completed topic, I aim to record:

- Concepts understood
- Programs implemented
- Practice problems solved independently
- Bugs encountered and how they were fixed
- Important interview questions
- Concepts that need further revision

A topic is considered complete when I can explain the concept, implement a basic example without copying, and answer relevant questions.

## Long-Term Goal

My goal is to build strong Core Java fundamentals, develop reliable problem-solving skills, and apply these skills to backend development with Spring Boot and full-stack application development.

This repository will grow gradually as I learn each topic. I will add new packages, examples, exercises, and tests only when they become relevant to my learning.
